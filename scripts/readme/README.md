# README graphics

Everything under `.github/assets/` is generated by the scripts here.

| File | Script | Notes |
| --- | --- | --- |
| `banner-{dark,light}.svg` | `banner.mjs` | animated hero; pure SVG + CSS keyframes |
| `terminal.svg` | `terminal.mjs` | animated terminal session, based on the CLI's real output |
| `pipeline-{dark,light}.svg` | `pipeline.mjs` | "how it works" diagram |
| `screens-src/*.png` | `capture.mjs` | 1600×1200 screenshots of the samples running in headless Chrome |
| `screens/*.webp`, `showcase.webp` | `showcase.mjs` | gallery stills and the animated tour |

The SVGs avoid SMIL, scripts and web fonts, keep a meaningful frame when animation is off, and honour
`prefers-reduced-motion`.

## Regenerating

```bash
node scripts/readme/banner.mjs
node scripts/readme/terminal.mjs
node scripts/readme/pipeline.mjs
```

Screenshots need the samples published to a local server and Google Chrome:

```bash
npm run build
node dist/cli.js serve --port 8797 --data .waa/server --token dev-token-0123456789abcdef &
for pair in dos:examples/hello-dos/HELLO.COM flash:examples/hello-flash/hello.swf \
            floppy:examples/hello-floppy/hello.img win32:examples/hello-win32/hello.exe \
            java:examples/hello-java/hello.jar linux:examples/hello-linux/hello; do
  name=${pair%%:*}; file=${pair#*:}
  node dist/cli.js build "$file" --out "out/$name" --force
  node dist/cli.js publish "out/$name" --to server --server http://localhost:8797 \
    --token dev-token-0123456789abcdef --slug "hello-$name"
done
node scripts/readme/capture.mjs --server http://localhost:8797 --out .github/assets/screens-src
node scripts/readme/showcase.mjs        # needs rsvg-convert, ffmpeg, cwebp and img2webp
```
